# BREATHEA 🌿
**Respira. Relaxa. Redescobre.**

BREATHEA é um jogo 2D interativo de respiração e relaxamento, desenvolvido com **Unity 2021 LTS e C#**. Oferece exercícios respiratórios guiados, animações sincronizadas e elementos ambientais interativos para proporcionar uma experiência calma e envolvente.

### Funcionalidades
- Exercícios respiratórios configuráveis.
- Esfera respiratória animada.
- Ambiente sincronizado com as fases respiratórias.
- Temporizador e contador de ciclos.
- Sistema de pausa, retoma e reinício.
- Sistema de gestão de áudio (em desenvolvimento).

### Tecnologias
- Unity 2021 LTS
- C#
- Unity UI
- Unity Coroutines
- Unity AudioSource
